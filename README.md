# 🌦️ Weather App – JavaScript Project

A simple and responsive Weather App built using **HTML**, **CSS**, and **JavaScript**.  
It fetches real-time weather data using a public weather API and displays temperature, humidity, wind speed, and weather conditions for any city.

---

## 🚀 Project Introduction

This project is a beginner-friendly weather application created using **Vanilla JavaScript**.  
It allows users to search for any city and instantly view its current weather details.

The main purpose of this project is to practice:

- Fetching data using JavaScript `fetch()`  
- Working with public APIs  
- Updating UI dynamically  
- Building a clean and responsive design  
- Handling errors and invalid inputs  

---

## ⭐ Features

- ✔️ Real-time weather data  
- ✔️ Search by city name  
- ✔️ Temperature, humidity & wind speed display  
- ✔️ Weather icons based on condition  
- ✔️ Responsive UI for all screen sizes  
- ✔️ Error handling (invalid city)  
- ✔️ Clean and modern interface  

---

| Technology   | Purpose |
|--------------|---------|
